# CSS-утилиты Lumos: справочник компактных классов

Короткая легенда для классов вида `f-c`, `g-2`, `br-4`, `b-d`, `c-l` — той
системы, что реально используется по всему проекту (см. любой компонент,
например `DraggableMaterialCard.jsx`: `className="material-card b-d br-4
p-2 g-2 f-c"`).

Определения — в `main.css`, секция `/* ===== КОМПАКТНЫЕ КЛАССЫ ===== */`
(искать по этому комментарию).

> В файле есть ещё более ранняя секция `/* ===== АТОМАРНЫЕ КЛАССЫ ===== */`
> (`.p-0`…`.p-8`, `.gap-0`…, `.text-*` и т.д. на `var(--space-N)`) — она
> старше и почти не используется в реальном коде компонентов. Если видишь
> `.p-1`/`.p-2`/`.p-3`/`.g-2` в двух местах файла — это не опечатка, это
> исторически два поколения одной идеи; там, где они пересекались буквально
> (одинаковый класс, разное значение), более новое (vmin/vw) побеждало в
> каскаде по порядку в файле — дублирующие мёртвые объявления удалены отдельно.

## Формат имени

`{свойство}-{значение}` или `{свойство}-{сторона}`. Значения — либо шкала
1-6 (`vmin`/`vw`, растёт с размером экрана — играет роль "отступа/радиуса,
пропорционального viewport"), либо буква стороны/полюса (`l` = light/left в
зависимости от контекста, `d` = dark).

## Layout (flex/grid)

| Класс  | CSS                                    | Когда использовать |
|--------|-----------------------------------------|---------------------|
| `.f`   | `display: flex;`                        | просто flex-контейнер, направление по умолчанию (row) |
| `.f-c` | `display:flex; flex-direction:column;`  | flex-колонка — самый частый контейнер карточек/списков |
| `.f-r` | `display:flex; flex-direction:row;`     | flex-строка (когда направление важно явно указать) |
| `.jc-c`  | `justify-content: center;`            | центрирование по главной оси |
| `.jc-sb` | `justify-content: space-between;`     | распределить по краям |
| `.ac-c`  | `align-content: center;`              | |
| `.ai-c`  | `align-items: center;`                | центрирование по поперечной оси |
| `.gr`  | `display:grid; grid-template-columns:1fr 1fr;` | сетка в 2 колонки (1 колонка в portrait — см. media query рядом) |

## Отступы и зазоры

| Класс  | CSS                     |
|--------|--------------------------|
| `.p-1` | `padding: 1vmin;`        |
| `.p-2` | `padding: 2vmin;`        |
| `.p-3` | `padding: 3vmin;`        |
| `.p-r` | `position: relative;` (⚠️ НЕ padding, несмотря на префикс `p-` — "position: relative") |
| `.g-1` | `gap: 1vmin;`             |
| `.g-2` | `gap: 2vmin;`             |
| `.m-0` | `margin: 0;`              |
| `.m-t-3`  | `margin-top: 3vw;`    |
| `.m-1-0`  | `margin: 1rem 0;` (верт. 1rem, гориз. 0) |
| `.m-0-1`  | `margin: 0 1rem;` (верт. 0, гориз. 1rem) |

## Границы и радиусы

| Класс   | CSS |
|---------|-----|
| `.b-l`  | `border: 1px solid var(--light);` |
| `.b-d`  | `border: 1px solid var(--dark);` |
| `.br-1` … `.br-6` | `border-radius: {1..6}vmin;` — чем больше число, тем круглее угол |
| `.out-l` | `outline: 3px dashed var(--light); outline-offset:5px;` — акцентная пунктирная обводка (напр. drag-over состояние) |
| `.out-d` | `outline: 5px solid var(--dark); outline-offset:5px;` |

## Цвет

| Класс   | CSS |
|---------|-----|
| `.bg-l` | `background-color: var(--light);` |
| `.bg-d` | `background-color: var(--dark);` |
| `.bg-b` | `background-color: var(--blueberry);` |
| `.c-l`  | `color: var(--light);` |
| `.c-d`  | `color: var(--dark);` |

## Текст

| Класс   | CSS |
|---------|-----|
| `.ta-l` | `text-align: left;` |
| `.ta-c` | `text-align: center;` |

## Размеры

| Класс    | CSS |
|----------|-----|
| `.wd`    | `width: 100%;` |
| `.hd`    | `height: 100%;` |
| `.ov-h`  | `overflow: hidden;` |
| `.i-32`  | `width/height: 1.5rem;` — фиксированная иконка (32px-сетка проекта) |
| `.i-reg` | `clamp(1.2rem, 1rem + 2vw, 2rem)` — адаптивная "обычная" иконка |
| `.i-logo`| `clamp(2.4rem, 2rem + 4vw, 4rem)` — адаптивная крупная иконка/лого |

## Пример использования

```jsx
<div className="material-card b-d br-4 p-2 g-2 f-c">
  {/* b-d: тёмная рамка · br-4: скругление 4vmin ·
      p-2: паддинг 2vmin · g-2: gap 2vmin между детьми ·
      f-c: flex-колонка */}
</div>
```

## Когда добавлять новый класс сюда

Если в `main.css` появляется новый класс формата `{property}-{value}` —
добавь строку в соответствующую таблицу выше. Если нужного свойства ещё
нет ни в одной таблице — заведи новую секцию по образцу существующих.
